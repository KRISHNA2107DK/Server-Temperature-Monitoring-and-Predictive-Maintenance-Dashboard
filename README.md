# Server Temperature Monitoring & Predictive Maintenance Dashboard

Interactive dashboard over the real lab heat-monitor logs (`Tempreture Data.zip`, 14 servers).
Critical threshold: **85 °C** per component.

## Setup (Windows, Python 3.11)
```bash
pip install -r requirements.txt
```

## Run (reproduces every output from the zip)
```bash
python src/pipeline.py
python src/export_charts.py
streamlit run src/dashboard.py
python -m pytest -q
```
PNG export uses `kaleido`, which needs Chrome or Microsoft Edge installed (Edge is built into Windows 11).
Dashboard opens at http://localhost:8501.

## Project layout
| Path | Purpose |
|---|---|
| `src/pipeline.py` | Reads CSVs directly from the zip, cleans, resamples to 1-min, detects >85 °C breaches + anomalies, computes risk ranking |
| `src/charts.py` | Plotly chart builders (line, bar, heatmap, box) |
| `src/export_charts.py` | Saves charts as standalone HTML in `results/charts/` |
| `src/dashboard.py` | Streamlit dashboard with top navigation: Overview · Temperature trends · Abnormal patterns · Predictive maintenance · Cooling & workload · Component guide; shared filter bar; CSV download buttons |
| `tests/test_pipeline.py` | 14 unit tests on a small hand-written fixture CSV (not real data) |
| `.streamlit/config.toml` | Light theme; charts are white cards on a grey background for contrast |
| `data/processed/` | Cached processed data (regenerated by pipeline) |
| `results/tables/` | `server_summary.csv`, `component_risk_summary.csv`, `critical_breach_events.csv`, `anomalies.csv` |
| `results/charts/` | Interactive HTML charts (Plotly JS loaded from CDN) |
| `results/charts/png/` | Same charts as static PNG images (1500 px wide) for slides/reports |
| `results/test_log.txt` | Result of the unit-test run |
| `results/pipeline_log.txt` | Console output of the pipeline run |

## Method (plain language)
- **Overheating:** any reading strictly above 85 °C. Consecutive hot readings (gaps ≤ 5 min) form one breach event.
- **Abnormal pattern:** a 1-minute average more than 4 standard deviations away from that component's previous hour.
- **Predictive maintenance:** straight-line trend of the last 3 days → °C/day and projected days until 85 °C; combined with breach and anomaly counts into CRITICAL / HIGH / WARNING / NORMAL.
See SPEC.md for all assumptions.

### Not verified / known limitations
- Some sensors report 0 °C (likely disconnected); they are kept, which lowers means but cannot cause false >85 °C alerts.
- HIGH via trend can fire on components with short, steep warm-up periods (linear projection over ≤ 3 days); review `trend_c_per_day` before acting.
